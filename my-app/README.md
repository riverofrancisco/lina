# my-app — First release (Create React App)

This is the first release of the portfolio site, built with Create React App.

## Quick info

- Framework: Create React App (React)
- Local dev: `npm start` (opens at http://localhost:3000)
- Build: `npm run build` (output to `build/`)

## Deployed URL

- https://linarivero-v1.vercel.app/

## Notes

- Standard CRA scripts are available in `package.json` (start, build, test, eject).
- To run locally: `npm install` then `npm start`.
